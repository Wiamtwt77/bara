# المحكمة السرية — الأدوار الملعونة

## نظرة عامة

لعبة اجتماعية استراتيجية. كل لاعب له **دور سري** و**هدف فوز مختلف**. البطاقات ملعونة — احتفظ بها طويلاً وقد تنفجر!

## الملفات

```
secret-court-v3/
├── index.html        ← اللعبة الكاملة (تعمل بدون خادم)
├── api/
│   └── game.js       ← API الذكاء الاصطناعي (اختياري)
├── vercel.json       ← إعدادات Vercel
└── README.md         ← هذا الملف
```

## التشغيل

### بدون خادم (موصى به)
افتح `index.html` مباشرة في المتصفح.

### على Vercel (مع AI اختياري)
1. ارفع المجلد إلى GitHub واربطه بـ Vercel.
2. أضف `OPENROUTER_KEY` في Environment Variables.
3. نفّذ Redeploy.

## كيف تُلعب

### ١. توزيع الأدوار (سرية)
كل لاعب يحصل على دور سري. لا أحد يعرف دور الآخر!

### ٢. حدث الجولة
يغير قواعد الجولة (مثلاً: الهجوم محظور، أو الجميع يحصل على ذهب).

### ٣. السحب
كل لاعب يسحب بطاقة واحدة:
- **فعل** (⚔️🛡️🔍💰💊) — يُستخدم فوراً
- **مورد** (📜💎🌟) — يُستخدم أو يُحتفظ به
- **ملعونة** (💣☠️🔥) — خطيرة إذا احتفظت بها!

**الحد: 3 بطاقات في اليد.**

### ٤. الكشف
تُعرض الأفعال دفعة واحدة. البطاقات الملعونة تُفحص:
- 💣 **القنبلة**: إذا يدك امتلأت (3/3) → تنفجر! (-3 ❤️)
- ☠️ **السم**: في نهاية كل جولة → -1 ❤️ حتى تتخلص منه
- 🔥 **اللعنة**: لا يمكنك سحب بطاقات

### ٥. الاتهام
تصويت سرّي. الأكثر أصواتاً يخسر 1 نفوذ. من صوّت صح يكسب 1 نفوذ.

## الأدوار السرية (6 أدوار)

| الدور | الهدف | القوة الخاصة |
|-------|-------|-------------|
| 🕵️ **المحقق** | اجمع 3 أدلة 📜 | كشف دور لاعب مجاناً |
| 🗡️ **القاتل** | اقتل 2 لاعبين | هجوم مجاني وأقوى (-3 ❤️) |
| 💰 **التاجر** | اجمع 10 ذهب | السرقة تسرق 3 بدلاً من 2 |
| ⭐ **السياسي** | اجمع 5 نفوذ | صوته يحتسب ضعف |
| 🎭 **المنشق** | كن آخر من يبقى | إذا وصل لـ 1 ❤️ ينجو تلقائياً |
| 🛡️ **الحارس** | حمِّ لاعبك حتى النهاية | يحمي لاعباً مجاناً |

## البطاقات

### فعل (تُستخدم فوراً)
- ⚔️ **هجوم**: -2 ❤️ للهدف (القاتل: -3)
- 🛡️ **درع**: تحمي من هجوم هذه الجولة
- 🔍 **كشف**: تعرف دور لاعب سرياً
- 💰 **سرقة**: تسرق 2💰 (التاجر: 3💰)
- 💊 **علاج**: +2 ❤️ لنفسك

### مورد (يُستخدم أو يُحتفظ)
- 📜 **دليل**: +1 دليل (للمحقق) أو بيعه بـ 1💰
- 💎 **ذهب**: +2 💰
- 🌟 **نفوذ**: +1 ⭐

### ملعونة (خطيرة!)
- 💣 **قنبلة**: استخدمها (-1 ❤️) أو إذا يدك امتلأت → تنفجر (-3 ❤️)!
- ☠️ **سم**: استخدمه (-1 ❤️) أو كل جولة -1 ❤️
- 🔥 **لعنة**: استخدمها (تفقد دورك لجولة) أو لا تستطيع السحب
