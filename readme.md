# المحكمة السرية: مصالح متعارضة (Shadow Tribunal)

لعبة سياسية واستراتيجية عميقة تعتمد على تمرير الهاتف، المصالح المتعارضة، الخيانات المدروسة، والاستغلال المظلم للوصول إلى السيادة المطلقة.

## أركان اللعبة الأساسية:
1. **الموارد الثلاثة:** 
   * ❤️ **الحياة (HP):** بقاؤك الجسدي.
   * ◆ **النفوذ (Influence):** عملة القوة وبناء السيادة.
   * ⭐ **السمعة (Reputation):** درعك الاجتماعي ومكانتك في المحكمة.
2. **الأفعال السرية والاستغلال:** إمكانية تنفيذ مؤامرات، حماية، تحالفات، أو **"استغلال مظلم"** لسحب موارد وحياة الخصوم قسراً لتحقيق تفوق ساحق على حساب سمعتك.
3. **المحكمة العادلة:** تصويت سري، أدلة مستمدة من الأفعال، ومحاكمات يديرها الذكاء الاصطناعي بقرارات حاسمة (براءة، إدانة، صفقات).
4. **شروط فوز متعددة:** البقاء وحيداً، بلوغ 25 نقطة نفوذ، الوصول إلى 100 سمعة، أو إعلان تحالف النصر النهائي.
