# المحكمة السرية ٢.٠ — Secret Court v2

## نظرة عامة

لعبة اجتماعية استراتيجية تفاعلية تعمل على المتصفح. لا جاسوس ثابت، لا أدوار دائمة. كل جولة قضية جديدة.

## الملفات

```
secret-court-v2/
├── index.html        ← الواجهة الكاملة (تعمل بدون خادم)
├── api/
│   └── game.js       ← API الذكاء الاصطناعي (اختياري)
├── vercel.json       ← إعدادات Vercel
└── README.md         ← هذا الملف
```

## التشغيل بدون خادم (موصى به)

افتح `index.html` مباشرة في المتصفح. اللعبة تحتوي على مكتبة أحداث وأجندات وأدوار مدمجة تعمل بالكامل محلياً.

## التشغيل على Vercel (مع AI اختياري)

### ١. رفع الملفات

ارفع المجلد كاملاً إلى GitHub ثم اربطه بمشروع Vercel.

### ٢. إعداد المفتاح

في Vercel:
Project Settings → Environment Variables

أضف:
- `OPENROUTER_KEY` = مفتاحك من OpenRouter
- `OPENROUTER_MODEL` = `openai/gpt-4o-mini` (اختياري)

### ٣. إعادة النشر

بعد إضافة المتغيرات، نفّذ Redeploy.

## كيف تُلعب

1. اختر عدد اللاعبين (3–8) وأدخل أسماءهم.
2. فعّل AI إذا أردت أحداثاً متنوعة (اختياري).
3. كل جولة:
   - 🎯 **أجندة سرية**: كل لاعب يرى مهمته ودوره السري.
   - ⚡ **حدث**: قضية تظهر مع تلميحات.
   - 🔒 **أفعال سرية**: اختر فعلاً وهدفاً سراً.
   - 🔓 **كشف**: تُعرض الأفعال دفعة واحدة مع التفاعلات.
   - 🎴 **أدلة**: اختر بطاقة من 3 متاحة.
   - ⚖️ **اتهام**: تصويت سر + دفاع + حكم القاضي.
   - 🌙 **نهاية**: حساب الأجندات والمكافآت.
4. **الفوز**: أول من يصل 7 نفوذ ⭐، أو يبقى أخيراً.

## الموارد

| المورد | الاستخدام |
|--------|-----------|
| 💰 ذهب | المقايضة، الخداع، بعض البطاقات |
| 🔮 معلومة | التجسس، الحماية |
| ⭐ نفوذ | الاغتيال، الهدف الرئيسي للفوز |

## الأدوار الديناميكية (تتغير كل جولة)

- ⚖️ **القاضي**: يقرر مصير المتهم.
- 👁️ **الشاهد**: يعرف فعلاً سرياً.
- ⚡ **المدعي**: يختار من يُتهم.
- 🛡️ **المحامي**: يمكنه الدفاع عن المتهم.
- 🕵️ **الجاسوس**: يعرف موارد لاعب.
- 🛡️ **الوسيط**: يُلغي فعلاً سرياً ضده.

## الأفعال السرية

| الفعل | التكلفة | التأثير |
|-------|---------|---------|
| 🗡️ اغتيال | 1 ⭐ | -2 HP للهدف |
| 🛡️ حماية | 1 🔮 | تحمي الهدف من الإيذاء |
| 🕵️ تجسس | 1 🔮 | تكشف أجندة ودور الهدف |
| 💰 سرقة | 1 ⭐ | تسرق 1 ذهب |
| 🤝 مقايضة | 1 💰 | تبادل موارد مع الهدف |
| 🎭 خداع | 1 💰 | تقلد فعل لاعب آخر |
| 🌙 انتظار | مجاني | لا شيء |

## ملاحظات

- لا تضع `OPENROUTER_KEY` داخل `index.html` أو GitHub.
- API يقرأ المفتاح من `process.env.OPENROUTER_KEY` فقط.
- اللعبة تعمل بالكامل بدون AI باستخدام المكتبة المدمجة.
