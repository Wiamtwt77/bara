# المحكمة السرية V2 — أثر الشبهة

لعبة اجتماعية استراتيجية. كل لاعب له **دور سري** و**هدف فوز مختلف**. البطاقات ملعونة — احتفظ بها طويلاً وقد تنفجر!

## الملفات

```
secret-court-v2/
├── index.html        ← اللعبة الكاملة (تعمل بدون خادم)
├── api/
│   └── game.js       ← API الذكاء الاصطناعي (اختياري)
├── vercel.json       ← إعدادات Vercel
└── README.md         ← هذا الملف
```

## التشغيل

### بدون خادم (موصى به)
افتح `index.html` مباشرة في المتصفح.

### على Vercel (مع AI اختياري)
1. ارفع المجلد إلى GitHub واربطه بـ Vercel.
2. أضف `OPENROUTER_KEY` في Environment Variables.
3. نفّذ Redeploy.

| الفعل | الشبهة |
|-------|--------|

| 🗡️ قتل | +2 |

## الإجراءات الوقائية
1. عقوبة الخمول (+1 شبهة)
2. حد الخيانة (مرة كل 3 جولات)
3. ضريبة الثروة (8+ ذهب)
4. حد الفضح (5 ضرر)
5. إعادة تدوير (مرة بالمباراة)
6. همس الأشباح العشوائي
7. حد الشبهة (15)
8. مراقبة عند 7+ شبهة
9. حد الجولات (12)
