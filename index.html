هذا الخطأ شائع جداً في تطوير المواقع عند استخدام لغة JavaScript، ويعني ببساطة أن **الكود يحاول تغيير أو قراءة خاصية `classList` لـ عنصر غير موجود في الصفحة (قيمته `null`)**. بمعنى آخر: الكود يتوقع وجود عنصر $HTML$ بمعرف (id) أو كلاس معني، ولكنه لم يجد هذا العنصر في الصفحة أثناء تشغيل Script. --- ## 🛠️ أسباب المشكلة وطريقة حلها ### 1. الكود يعمل قبل تحميل عناصر الصفحة (السبب الأشهر) إذا كان ملف الـ JavaScript يتم استدعاؤه في رأس الصفحة (``) بدون أي تأخير، سيعمل الكود **قبل** أن يتم بناء أجزاء الـ HTML في المتصفح. * **الحل 1 (الأفضل):** إضافة الخاصية `defer` عند استدعاء ملف الكود في قسم ``: ```html ``` * **الحل 2:** نقل السطر الخاص باستدعاء ملف الـ JS ليكون في **آخر الصفحة** تماماً، قبل إغلاق وشم ``. --- ### 2. خطأ في اسم العنصر (Typo) أو الـ ID إذا كان الكود الذي أنتجه الذكاء الاصطناعي يبحث عن عنصر كالتالي: ```javascript const element = document.getElementById("my-button"); element.classList.add("active"); // هنا يحدث الخطأ إذا لم يجد my-button ``` وكان الاسم في الـ HTML مكتوباً بشكل مختلف (مثل `myButton` أو `my_button`)، فلن يجد العنصر. * **الحل:** تأكد من مطابقة الـ `id` أو `class` بين ملف الـ HTML وكود الـ JavaScript تماماً. --- ### 3. الكود يشتغل على صفحة لا تحتوي هذا العنصر إذا كنت تستخدم نفس ملف الـ JS لعدة صفحات داخل الموقع، وقد يكون هذا العنصر موجواً في "الصفحة الرئيسية" مثلاً وغير موجود في صفحة "اتصل بنا". * **الحل (التحقق الأمني قبل التشغيل):** يمكنك تعديل الكود ليفحص وجود العنصر أولاً باستخدام الـ Optional Chaining (`?.`) أو شرط `if`: **طريقة الـ Optional Chaining (الأسهل):** ```javascript // تمنع حدوث الخطأ وتتجاهله إذا كان العنصر null document.getElementById("my-button")?.classList.add("active"); ``` **طريقة الشرط:** ```javascript const element = document.getElementById("my-button"); if (element) { element.classList.add("active"); } ``` --- ## 💡 كيف تطلب من الذكاء الاصطناعي إصلاحها تلقائياً؟ قم بنسخ هذا النص وأرسله للذكاء الاصطناعي الذي يكتب لك الكود: > "ظهر لي هذا الخطأ عند تشغيل الموقع: > `Cannot read properties of null (reading 'classList')` > يرجى مراجعة الكود وإضافة تحقق أمني (Null Check) قبل استدعاء `classList` لجميع العناصر، والتأكد من إمكانية عمل الكود بعد تحميل الـ DOM كاملاً."
